## What is implemented

The public prototype provides deterministic structural claim/evidence metadata checks; assumption-closure flags; dependency and warrant-scope review; revision comparisons using stable identifiers; local SHA-256 source-byte and exact-quote anchors; and synthetic test fixtures.

## What is NOT established

- No independent scientific truth, mathematical proof, domain transfer, or hardware validation.
- A matching source excerpt does not establish that the excerpt supports the claim.
- Author-declared review, applicability, scope, or provenance does not independently certify them.
- Unit-test success does not demonstrate external scientific validity, originality, or superiority.
- Historical external-readiness criteria are fail-closed; no independently rated effectiveness result is claimed.

## Pre-evaluation gate (must be completed before effectiveness claims)

1. Fix the precise question: does the targeted checker detect material revision risks better than a simple equally informed comparator, while controlling false alarms?
2. Select 8–12 eligible authorized real revision cases under a documented inclusion rule; log excluded candidates.
3. Pin both versions, all evidence, hashes, exact software SHA, prompts, model settings, reviewer instructions, and time budgets.
4. Two independent qualified reviewers label each case `yes`, `no`, or `uncertain`, record inspected evidence and reasoning, and remain blind to system predictions.
5. Run targeted checker and equal-information generic critic on the **same** versions and supporting evidence. Include a deterministic basic-checklist baseline when feasible.
6. Preserve individual labels, disagreements, abstentions, all predictions, and error examples. Report TP/FP/FN/TN, precision, recall, specificity, and abstention coverage only on determinate agreed labels, with denominators.
7. Report small-N findings as descriptive; no significance, certification, or novelty claims. If reviewer or source access is missing, report **not evaluated**, not a synthetic substitute.

## Stop / no-go conditions

No external comparison if source permissions, matched evidence access, independent labels, or frozen inputs are missing. Any protocol change after seeing predictions must be versioned and labeled exploratory. Keep private documents and reviewer identities outside this public repository.

## Implementation guardrail

Do not extend the research engine merely to improve benchmark results. Changes after this baseline belong in separate commits/branches and must be distinguished from the frozen version.
