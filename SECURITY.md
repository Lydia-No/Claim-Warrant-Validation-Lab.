# Security and data handling

This is a public repository and continuous integration logs may be public. Never commit secrets, private research materials, proprietary third-party blueprints, authentication tokens, private access links or restricted research keys.

The program runs locally and does not make external requests or transmit records. It accepts JSON from disk and emits a report to standard output. Treat untrusted input as untrusted data; no sandboxing guarantee is provided.

Report suspected leaks privately to the repository owner before filing a public issue. Avoid including sensitive contents in a public report.
