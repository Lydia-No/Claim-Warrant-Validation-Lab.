# Contributing

Issues proposing independent, synthetic reproductions or test cases are welcome.

Do not submit unpublished third-party designs, confidential materials, proprietary blueprint text, trade secrets, or private research files. Do not upload partner materials without authorization.

Please describe the expected finding, the minimal synthetic reproduction, and the limitation it tests. Public repository access does not constitute permission to use the code under an open-source license; contact the project owner about reuse or licensing.
